# RSA Creations - Storefront Frontend

Handcrafted artisanal e-commerce web storefront for **RSA Creations**.

## Features
- **Artisanal Showcase**: Hand-thrown ceramics, loom-woven textiles, terracotta planters, and heirloom decor.
- **Dynamic Delivery Estimation**:
  - Kolkata Metropolitan Area: Flat ₹60
  - Rest of West Bengal: Flat ₹100
  - Rest of India: Flat ₹150
  - Free Doorstep Delivery: Orders ₹1,999+
- **Customer Authentication**: Sign up and log in via email or 10-digit Indian mobile number.
- **Address Management**: Delivery address profile pre-filling for 1-click checkout.
- **Admin Operations Hub**: Manage production, tracked dispatch, and customer orders at `/admin.html`.

## Deployment
Deploy this folder as a static site to:
- **Vercel** / **Netlify** / **GitHub Pages** / **Firebase Hosting**

To connect with your backend API on Render/Railway/Heroku, ensure your backend URL is accessible.
